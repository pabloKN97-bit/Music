# GlassPlayer

Reproductor de MP3 para Android con estética tipo AIMP y reproductor con efecto "cristal" (estilo Apple Music).

## Funciones
- Lista de reproducción de tus MP3 locales, con reproducción en segundo plano, notificación y controles de pantalla de bloqueo.
- Portadas por canción: desde la galería, desde la portada incrustada del MP3 o desde Deezer.
- Widget de pantalla de inicio con fondo de cristal.
- Búsqueda en Deezer (portadas y previews de 30 s; la API pública no ofrece canciones completas).

## Obtener el APK
Cada push a `main` ejecuta GitHub Actions: pestaña **Actions → Build APK → último run → Artifacts → GlassPlayer-debug-apk**.
También se puede compilar con Android Studio (*Build > Build APK(s)*).
